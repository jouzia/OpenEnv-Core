# OpenEnv: Sentient Study OS (v4.0)

**OpenEnv** is a next-generation academic dashboard designed specifically for BCA students to manage complex logic, track academic performance, and reduce study burnout through a "sentient" interface.

## Key Features

* **The Logic Forge:** A custom module that "shatters" complex syllabus text or code into manageable, atomic tasks.
* **Bud AI (Sentient UI):** A built-in AI companion that reacts emotionally to your study progress using dynamic SVG states and Framer Motion physics.
* **Provisional CGPA Tracker:** Real-time performance projection. Adjust subject mastery percentages to see your estimated semester GPA instantly.
* **Dual-Core Mascots:** Switch between **Arman (Logic Core)** and **Zara (Analytics Core)** to suit your current study focus.
* **Adaptive Glassmorphism:** A high-end, dark-themed UI optimized for long-duration coding and study sessions.

## Tech Stack

* **Frontend:** React.js
* **Animations:** Framer Motion
* **Icons:** Lucide-React
* **Styling:** Modern CSS (Glassmorphism & Neumorphism)
* **Deployment:** Vercel (Optimized for rapid delivery)
